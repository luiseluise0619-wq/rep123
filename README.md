# 주소 분류 · 지역별 엑셀 분리 · 모바일 구글지도 생성

주소 데이터(44,075건 규모)를 정규표현식으로 파싱해 **시도 / 구군 / 동네**로 분류하고,
① 시도별 시트로 분리한 엑셀과 ② 모바일용 독립 실행형 구글지도 HTML을 생성합니다.

## 실행 방법

```bash
python 주소_분류_및_지도생성.py
```

- 입력: 스크립트와 같은 폴더의 `exceldata1.xlsx`
  (다른 파일을 쓰려면 스크립트 상단 `INPUT_XLSX` 경로만 수정 — 윈도우 경로는 이미 `r''` 처리)
- 출력:
  - `지역별_주소_분류.xlsx` — 시도별 시트 + `기타` 시트
  - `모바일_구글지도.html` — 스마트폰에서 파일만 열면 바로 실행

의존성: `openpyxl` (지도 라이브러리는 `vendor/`에 동봉되어 인터넷 없이도 로드됨)

```bash
pip install openpyxl
```

## 입력 / 출력 컬럼 규약

입력 엑셀:

| 열 | 내용 |
|----|------|
| A  | 주소 |
| D  | 전화번호 |
| E  | 사업자 등록번호 |

결과 엑셀(각 시트 공통):

| 열 | A | B | C | D | E | F | **G** | **H** |
|----|---|---|---|---|---|---|-------|-------|
| 내용 | 원본주소 | 시도 | 구군 | 동네 | 상세주소 | 분류상태 | **전화번호** | **사업자등록번호** |

> 입력 **D열(전화번호) → 결과 G열**, 입력 **E열(사업자등록번호) → 결과 H열**로
> 행 순서를 그대로 유지한 채 정리됩니다.

## 주소 분류 규칙 (정규표현식)

- **시도**: 첫 토큰이 광역자치단체 목록과 일치 (서울특별시·경기도 … 및 데이터 내 `전남광주통합특별시` 포함)
- **구군**: 시도 뒤의 `○○시 / ○○군 / ○○구` 토큰 (예: `수원시 팔달구`처럼 시+구 동시 인식)
- **동네**: `동 · 로(대로 포함) · 길 · 리 · 읍 · 면 · 가` (한글로 시작)
  - ① 괄호 안 법정동을 최우선 (예: `…27(남문로1가)` → `남문로1가`)
  - ② 없으면 본문 토큰 (`북문로3가`·`효자동1가`처럼 `가`로 끝나거나 `나성북1로`처럼 숫자가 섞여도 인식)
  - 첫 글자가 한글이 아닌 건물번호 `102동`·`S001동` 등은 제외
- **기타**: 시도가 없는 항목만 `기타` 시트로 (예시 데이터에선 주소가 아닌 `#REF!` 오류 1건뿐).
  분류 여부와 무관하게 **모든 행은 반드시 저장**되어 데이터가 사라지지 않습니다.

분류 결과(예시 데이터 44,075건): **정상 44,074건 / 기타 1건(`#REF!`)**, 시도 시트 18개 + `기타` 1개.

## 모바일 구글지도 (`모바일_구글지도.html`)

- **독립 실행형**: 별도 웹 서버 없이 파일을 열면 바로 실행 (Leaflet·MarkerCluster는 `vendor/`에서 인라인)
- **배경 지도**: API 키가 필요 없는 구글 지도 타일 레이어
- **마커 클러스터**: 4만 건 이상도 튕기지 않도록 청크 로딩 + 클러스터링
- **🎯 GPS 버튼**: 실시간 내 위치 추적 → 현재 위치에 빨간 마커 표시 후 이동
- **구글 길안내 팝업**: 마커를 누르면 주소·전화번호와 함께 **🚗 구글 길안내** 버튼 표시
  (길안내 목적지는 근사좌표가 아닌 **실제 주소 문자열**로 전달되어 구글이 정확히 검색)

### 좌표에 대한 참고 (중요)

기본 지도(`주소_분류_및_지도생성.py`)는 **API 키 없이 오프라인에서 동작**하도록, 각 주소를
소속 **행정구역(시도/구군) 중심좌표 + 결정적 지터(jitter)** 위치에 표시합니다. 따라서 점 위치는
**밀집도·분포 파악용 근사치**입니다. (길안내 버튼은 근사좌표가 아닌 실제 주소 문자열로 연결됩니다.)

**번지 단위 실제 좌표가 필요하면** 아래 무료 지오코딩 스크립트를 쓰세요.

## 실제 좌표 붙이기 — 무료 지오코딩 (`실주소_지오코딩.py`)

무료 지오코딩 백엔드를 **설정값 한 줄로 교체**해 실제 위·경도로 지도를 다시 만듭니다.

```bash
# 1) 실주소_지오코딩.py 상단 CONFIG 에서 BACKEND 와 키 입력
# 2) 실행
python 실주소_지오코딩.py
```

| BACKEND | 비용 | 키 | 비고 |
|---------|------|-----|------|
| `VWORLD` (기본) | 무료 | 발급 필요 (vworld.kr) | 국토부 공식. 도로명→지번 자동 재시도 |
| `KAKAO` | 무료 | 발급 필요 (developers.kakao.com) | 하루 10만 건 무료. **새 앱을 만들면 기존 앱과 키·쿼터 분리** |
| `NOMINATIM` | 무료 | **불필요** | 초당 1건·대량 금지 → 소량 테스트용 |

특징:
- 세 백엔드 모두 **WGS84로 좌표 수신** → 좌표계 변환 불필요
- **캐시(`geocode_cache.json`)** 로 중단 후 재시작 (성공한 주소는 재호출 안 함)
- 초당 호출 제한 + 실패 재시도(백오프), **중복 주소는 1회만 호출**
- 지오코딩 실패/미매칭 주소는 기존 **행정구역 근사좌표로 자동 폴백**
- 표준 라이브러리(`urllib`)만 사용 → 별도 설치 불필요

> 실행하면 `모바일_구글지도.html` 이 실제 좌표로 갱신됩니다(미확보분만 근사좌표 유지).

```
exceldata1.xlsx            # 예시 입력 데이터
지역별_주소_분류.xlsx       # 예시 출력 (시도별 시트)
모바일_구글지도.html         # 예시 출력 (모바일 지도)
```
