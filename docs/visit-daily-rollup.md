# 방문 결과 자정 누적

사업자별 거절·완료는 MYBOX `현장방문_사업자방문결과_v1`에 저장됩니다. 날짜 기준은 한국시간(Asia/Seoul)입니다.

## 자동 집계

`web/vercel.json`의 예약 작업은 매일 15:00 UTC(한국시간 00:00)에 `/api/visit-daily-rollup`을 호출합니다. Vercel Hobby에서는 해당 시각부터 59분 이내에 실행될 수 있으므로, 프로그램은 실행 시각과 무관하게 **전날까지** 마감합니다. 중복 호출돼도 이미 마감한 날짜의 수를 다시 더하지 않습니다.

MYBOX `현장방문_일별집계_v1` 폴더에 `일별집계.json`과 `방문결과_일별집계.xlsx`가 저장됩니다. 엑셀에는 날짜별 거절·완료·일일 합계와 누적 수가 들어갑니다. 관리 화면의 `엑셀 내려받기`는 마감한 날짜에 오늘의 현재 기록을 추가합니다. `사업자별현재결과` 시트는 과거 이력이 아니라 각 사업자의 최신 상태입니다.

## 아직 필요한 운영 설정

Vercel 프로젝트의 Production 환경 변수에 `CRON_SECRET`(임의 문자열 16자 이상)을 직접 저장하고 최신 배포를 다시 배포해야 예약 호출이 인증됩니다. 비밀값은 코드·채팅·스크린샷에 넣지 않습니다. 설정 전 예약 경로는 503 `SETUP`을 반환하며 집계 파일을 만들지 않습니다.

작업 실패 시 Vercel의 Cron Jobs 실행 로그를 확인하고, 관리자 페이지에서 `지난 날짜 집계 저장`을 눌러 재시도할 수 있습니다. MYBOX 접근 오류나 저장 공간 부족을 확인하지 않은 채 성공으로 간주하지 않습니다.

## 집계 기준

같은 사업자를 **같은 날** 여러 번 수정하면 그날 마지막 결과만 셉니다. 마감한 날짜의 숫자는 이후 수정해도 고정됩니다. 따라서 같은 사업자를 다른 날짜에 수정하면 두 날짜에 각각 기록될 수 있습니다. 현재 상태별 사업자 수와 날짜별 누적 처리 건수는 서로 다른 지표입니다.

이 기능을 넣기 전에 한 사업자의 수정 이력이 10건을 넘었다면 오래된 일부 날짜는 기존 저장 구조상 복구할 수 없을 수 있습니다. 최초 자동 집계 결과를 운영 기록과 대조해야 합니다.
