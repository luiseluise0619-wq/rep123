# MYBOX 사진 업로드 (무료 플랜 내 중단형 운영)

사진 바이너리는 MYBOX에만 보관합니다. 기존 Vercel 사이트의 원주소 버튼이
Apps Script 사진 페이지를 새 창으로 엽니다. Apps Script는 로그인, MYBOX API 중계,
프로젝트 전역 잠금만 담당하며 Google Drive/Sheets/Forms에 사진을 저장하지 않습니다.

## 비밀값 설정 — 절대 채팅·소스·GitHub에 올리지 않기

Apps Script **프로젝트 설정 → 스크립트 속성**에 소유자가 직접 등록합니다.

- `MYBOX_TOKEN`: MYBOX 설정에서 발급한 개인 액세스 토큰.
- `PHOTO_TEAM_PASSWORD`: 최소 8자, 권장 12자 이상 무작위 팀 접속 암호. 8~15자도 허용합니다.

MYBOX PAT는 계정 내 일반 파일 전체에 접근할 수 있으므로 전용 계정 권장.
서버 코드는 앱 전용 폴더로 접근을 제한하지만, PAT 자체가 그 폴더로 제한되는 것은 아닙니다.
프로젝트 편집자는 비밀값에 접근할 수 있으므로 직원에게 편집 권한을 주지 않습니다.
직원에게는 사진 페이지와 팀 암호만 전달합니다. 표시명은 자기 신고값이며 본인 인증이 아닙니다.
PAT/팀 암호 변경 시 모든 기존 세션이 무효화됩니다. PAT는 최대 180일로 갱신해야 합니다.

## 설치

1. 저장소 루트에서 `node scripts/bundle-photo-backend.cjs` 실행.
2. 생성된 로컬 `../work/mybox-photo-bundle.gs`의 **내용 전체**를 기존 Apps Script의 `Code.gs`에 넣고 저장.
3. 위 비밀값 두 개를 소유자가 직접 등록.
4. **배포 → 새 배포 → 웹 앱**, 실행 사용자=소유자, 액세스=모든 사용자.
   최종 공개 배포와 Google 권한 승인은 소유자 확인 후 진행합니다.
   Gmail/Drive/연락처 읽기 권한은 사용하지 않으며 외부 URL 연결 권한만 필요합니다.
5. 발급된 `/exec` URL만 `web/photo-config.js`의 `webAppUrl`에 등록 후 GitHub/Vercel 배포.
6. 실제 계정으로 접속·용량 조회·테스트 업로드·재조회가 성공하기 전 연결 완료로 표시하지 않기.

## 무료 안전 장치와 한계

- 원주소 42,401곳 × 최대 2장 × 200,000 bytes = 최대 **16,960,400,000 bytes (약 17GB)**.
- 브라우저에서 긴 변 최대 1600px, 장당 200KB 이하 JPEG로 변환. 자르지 않음.
- 저화질로도 용량이 줄지 않으면 거절. 사용자가 날짜·현장 가독성을 확인해야 저장.
- EXIF 촬영일/GPS는 제거됩니다. 사진에 인쇄된 날짜는 픽셀로 유지되나 읽기 쉬움은 보장 못함.
- 입력 방문일, 입력 담당자명, MYBOX 서버 생성 시각을 구분. 방문·촬영의 진위 보증 아님.
- 서버가 원주소 allowlist, 파일 길이/종류/해상도, 확인 체크, 2장 제한을 재검증.
- 모든 RPC를 Apps Script 전역 잠금으로 직렬 처리. 동일 사진 해시로 재시도 중복 방지.
- 다른 직원 처리 중(BUSY)일 때만 브라우저가 1.5·3·5·8초(+최대 0.5초 무작위 지연) 뒤 재시도합니다.
  인증·용량·네트워크 오류는 자동 반복하지 않습니다. 이 대기는 서버 동시 처리 용량을 늘리는 기능이 아닙니다.
- 개인 기기에서만 선택적으로 로그인 8시간 유지. 암호 대신 서명 세션만 저장하며 서버 만료를 연장하지 않습니다.
  기본값은 미선택이며, 브라우저 저장 차단 시 현재 탭의 메모리 세션으로 동작합니다.
- 모바일 큰 사진 선택 버튼, 선택 사진별 취소, 단계 안내, 하단 고정 저장 버튼과 장별 진행률을 제공합니다.
- 직원의 파일 삭제·덮어쓰기 기능 없음. 앱 외부에서 폴더가 변경되면 안전하게 중단.
- 용량은 계정 전체 사용량 기준 **min(24GB, 실제 할당량−1GB)**에서 저장 중단.
- 추가로 하루 저장 시도 1,000회·사진 보기 2,000회·외부 요청 전체 10,000회에서 중단.
  이 수치는 앱 내부의 보수적 상한이며 실제 서비스/계정 한도가 먼저 닿을 수 있습니다.
- 유료 플랜/결제 수단/자동 업그레이드를 만들지 않습니다. 한도를 넘으면 오류로 중단합니다.
- Google 무료 호출 한도는 다른 스크립트와 공유될 수 있고, MYBOX 제한은 2026-12-31 이후 변경 가능.
- 공용 암호 방식은 개인별 권한·공식 본인 인증·완전한 감사 이력을 제공하지 않습니다.
  이름별 제한과 별개로 서버 전역에서 로그인 실패 20회 누적 시 10분 잠금합니다.
  공격자가 잠금을 유발하면 정상 직원의 신규 로그인도 잠시 제한될 수 있습니다.
  잠금은 보조 수단이며 흔한 단어·연속 숫자 대신 강한 무작위 암호가 필요합니다.
- 공개 `/exec` HTML은 누구나 열 수 있지만 사진 조회·저장은 유효한 서명 세션이 필요합니다.
  무료 공용 서버는 DoS/서비스 중단에 대한 무제한 가용성을 보장하지 않습니다.

## 검증

`node --test tests/photo-ui.test.cjs tests/photo-backend.test.cjs tests/address-data.test.cjs`

노드 테스트는 Apps Script 서비스와 MYBOX 응답을 대체한 단위/시나리오 테스트입니다.
실계정 연결·권한 승인·실제 사진 저장을 대신하지 않습니다.

## 인원·트래픽 해석

지도 정적 페이지 조회와 로그인·사진 API 사용량은 서로 다릅니다. 부하 테스트 전에는 동시 사용자 수를 보장하지 않습니다.
앱의 하루 저장 시도 1,000회는 주소당 2장 기준 최대 500곳분입니다. 한 직원이 하루 20곳을 방문한다면
산술적으로 25명분이나, 실패 재시도·사진 조회·폴더 탐색·다른 스크립트 사용량 때문에 실제 한도가 먼저 닿을 수 있습니다.
Google의 사용자당 동시 실행 30개는 30명 동시 업로드 보장이 아닙니다. 현재 서버는 사진 수량·무료 한도를
안전하게 지키기 위해 RPC를 한 번에 하나씩 처리하며, 몰리면 제한적으로 대기 후 재시도합니다.
실제 운영은 적은 인원으로 확인한 후 늘려야 합니다. 지도 방문자 수·사진 처리량에 대한 실측 부하 시험은 아직 하지 않았습니다.
